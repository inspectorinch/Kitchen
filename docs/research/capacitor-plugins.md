# Capacitor plugins (checked 2026-11-25; all on Capacitor 8)
Capawesome plugins (`@capacitor-firebase/*`, `@capacitor-mlkit/*`) are **unofficial but the de facto standard**; Capacitor's own are `@capacitor/*`. Each lives behind a `src/platform/*` adapter, so a swap stays local. Always run `npx cap sync` after install and run `npm view <pkg> version` before pinning (npm pages I read showed stale numbers).

## Apple rule (App Store Review Guideline 4.8)
Apps that use a third-party or social login (the guideline names Google Sign-In) for the primary account must also offer an equivalent login service that limits data to name and email, lets users hide their email, and does not track for ads without consent. Sign in with Apple meets this. Exceptions: only your own account system, enterprise/education, client apps for a specific third-party service. **Kitchen offers Google, so Apple sign-in is required on iOS.** Email and password alone would be exempt, but Architecture lists Google, so keep Apple. Also 5.1.1(v): account creation requires in-app account deletion; plan a delete-account callable function. Source: developer.apple.com/app-store/review/guidelines (read 2026-11-25). Android has no equivalent rule.
